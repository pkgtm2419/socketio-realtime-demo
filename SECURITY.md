# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0.0 | :x:                |

---

## Reporting a Security Vulnerability

If you identify a security issue in WebSocket handshake token verification, transport interception, or denial-of-service vulnerabilities, please do **NOT** open a public issue.

Report vulnerabilities securely to:
- **Email:** `pawangtm2419@gmail.com`
- **Subject:** `[SECURITY VULNERABILITY] socketio-realtime-demo`

We will review the submission, reproduce the vulnerability within 48 hours, and coordinate a patch release.
